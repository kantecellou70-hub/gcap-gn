## Format d'entrée

Chaque incident est documenté selon le modèle suivant :

```
### INCIDENT-YYYY-NNN — <titre court>

| Champ | Valeur |
|-------|--------|
| Date/heure début | YYYY-MM-DD HH:MM (UTC) |
| Date/heure fin | YYYY-MM-DD HH:MM (UTC) |
| Durée | X heures Y minutes |
| Scénario PCA | A / B / C / D / Autre |
| Sévérité | P1 (Critique) / P2 (Haute) / P3 (Modérée) / P4 (Basse) |
| Tenants affectés | Liste ou "Tous" |
| Fonctionnalités affectées | ... |
| Cause racine | ... |
| Actions prises | ... |
| Prévention future | ... |
| Auteur du rapport | Nom, rôle |
```
